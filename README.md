### Installation   
Place this mod inside `C:\Program Files (x86)\Steam\steamapps\common\7 Days To Die\Mods` folder.

### Testing
Use any Mining Tool for 1 minute and you should see tooltip and buff effect of Mining skill increasing.

You can check your Mining level by opening the usual character skills UI. 

### Bug 
If used on a server, player's progression will reset after a while; randomly over many hours of gameplay for each player on the server.
